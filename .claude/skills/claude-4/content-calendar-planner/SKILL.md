# Content Calendar Planner

## Triggers
- User wants to plan content across platforms
- User says "content", "calendar", "social media", "LinkedIn", "YouTube"

## What It Does

### Platforms
```
LinkedIn: Professional content, thought leadership
YouTube: Long-form videos, tutorials
Blog: In-depth articles
Twitter/X: Quick updates, threads
Instagram: Visual content, stories
```

### Content Planning
```
1. GOALS
   → What to achieve
   → Target audience
   → Key messages
   
2. THEMES
   → Weekly/monthly themes
   → Content pillars
   
3. CALENDAR
   → Platform-specific posting schedule
   → Content mix (educational, promotional, engagement)
```
