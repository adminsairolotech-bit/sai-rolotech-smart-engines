# Interview Prep Coach

## Triggers
- User wants interview preparation
- User says "interview", "prep", "mock interview", "questions"

## What It Does

### Interview Types
```
TECHNICAL: Coding, system design, problem-solving
BEHAVIORAL: STAR method, past experiences
MANAGERIAL: Leadership, team handling
PRODUCT: Product sense, metrics, strategy
CASE: Business case analysis (consulting)
```

### Output Format
```
# Interview Prep: {Role Type}

## Most Likely Questions

### Tell Me About Yourself
{Template answer}

### Strengths/Weaknesses
Strength: {Example with evidence}
Weakness: {Real weakness + how you're addressing it}

## Top {X} Technical Questions
1. {Question}
   - What they're testing: {Skill}
   - Answer approach: {Method}
   - Example: {If applicable}

2. {Question}
...

## Top Behavioral Questions (STAR)

### Q: {Question}
**Situation:** {Context}
**Task:** {Your responsibility}
**Action:** {What you did}
**Result:** {Outcome + metrics}

### Q: {Question}
...

## Things to Remember
✓ {Do 1}
✓ {Do 2}
✗ {Don't 1}
✗ {Don't 2}

## Red Flags to Avoid
- {Mistake 1}
- {Mistake 2}
```

## Commands
| Command | Action |
|---------|--------|
| `interview prep` | Full prep |
| `mock interview` | Practice Q&A |
| `technical questions` | Tech only |
| `behavioral questions` | STAR practice |
