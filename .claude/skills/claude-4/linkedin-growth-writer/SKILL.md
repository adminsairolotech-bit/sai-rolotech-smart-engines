# LinkedIn Growth Writer

## Triggers
- User wants to write LinkedIn posts/content
- User says "LinkedIn", "professional post", "thought leadership"

## What It Does

### Post Types
```
EDUCATIONAL: Share knowledge, tips, how-tos
PERSONAL: Behind-the-scenes, story, values
ENGAGEMENT: Questions, polls, discussions
PROMOTIONAL: Product/service announcements
```

### Output Format
```
## Post Format

### Hook (First 2 lines - visible before "more")
{Attention-grabbing opening}

### Body
{Value-packed content}

### Call to Action
{Question or engagement prompt}

---

### Hashtags
#{tag1} #{tag2} #{tag3} #{tag4} #{tag5}

### Timing
Best time: {Suggested day/time}
```

### Post Templates

#### Educational Post
```
{Valuable insight or tip}

Here's why this matters:
• {Point 1}
• {Point 2}
• {Point 3}

What's your experience with this?
👇 Drop a comment

#{Relevant hashtags}
```

#### Personal Story
```
A {X} ago, I made a mistake that taught me {lesson}.

{Story briefly - 2-3 sentences}

Here's what I learned:
1. {Lesson 1}
2. {Lesson 2}
3. {Lesson 3}

What mistake taught you something valuable?

#{Relevant hashtags}
```

#### Thought Leadership
```
Hot take: {Controversial/opinion statement}

{Elaborate with reasoning}

Most people think {common belief}.
But {your perspective}.

The reality is {your conclusion}.

What's your take?
👇

#{Relevant hashtags}
```

### Growth Tips
```
- Post 3-5x per week
- Respond to all comments within 1 hour
- Use line breaks for readability
- Keep posts 150-300 words
- Use 3-5 relevant hashtags
- Post when audience is active (Tue-Thu, 8-10am, 12-1pm)
```

## Commands
| Command | Action |
|---------|--------|
| `write post` | Generate post |
| `linkedin thread` | Twitter-style thread |
| `improve post` | Enhance existing |
