# Resume/CV Improver

## Triggers
- User wants to improve resume
- User says "resume", "CV", "ATS", "job application"

## What It Does

### Improvement Areas
```
CONTENT: Bullet points, achievements, metrics
ATS: Keywords, formatting for robots
STRUCTURE: Sections, flow, hierarchy
ROLE FIT: Customize for specific job
IMPACT: Quantify achievements
```

### Output Format
```
# Resume Analysis & Improvement

## Overall Score: {X}/10
{Strengths and weaknesses overview}

## Key Issues Found

### 🔴 Critical (Must Fix)
1. {Issue} - {Fix}

### 🟡 Important (Should Fix)
1. {Issue} - {Fix}

### 🟢 Nice to Have
1. {Issue} - {Fix}

## Improved Resume

### {Name}
{Contact info}

### Professional Summary
{Rewritten summary - 2-3 lines, not generic}

### Experience

**{Job Title} | {Company} | {Date}**
- {Impact bullet 1} ({Metric})
- {Impact bullet 2} ({Metric})
- {Impact bullet 3} ({Metric})

**{Job Title} | {Company} | {Date}**
...

### Skills
| Category | Skills |
|----------|--------|
| {Category} | {Skill 1}, {Skill 2} |

## ATS Optimization
**Keywords detected in job posting:**
- {Keyword 1} - Add to skills
- {Keyword 2} - Add to experience
- {Keyword 3} - Currently missing

**Suggestions:** {How to naturally incorporate}

## Role-Specific Customization
For: {Job Title} at {Company}
- Mirror their language
- Highlight relevant projects
- Reorder skills by relevance
```

## Commands
| Command | Action |
|---------|--------|
| `improve resume` | Full improvement |
| `ATS check` | Keyword optimization |
| `customize for role` | Job-specific tailoring |
