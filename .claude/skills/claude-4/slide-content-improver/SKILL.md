# Slide Content Improver

## Triggers
- User wants to improve presentation slides
- User says "improve slides", "presentation", "slide content"

## What It Does

### Improvement Types
```
CONTENT: Better messaging, clearer points
VISUAL: Layout, hierarchy, visual balance
DATA: Charts, graphs, key numbers
FLOW: Story arc, transitions
IMPACT: More memorable, actionable
```

### Output Format
```
# Slide Content Improvement

## Before → After

### Slide {Number}: {Title}

**BEFORE (Current):**
{Original content}

**AFTER (Improved):**
{Improved content}

**Why better:** {Reason for change}

---

## Slide-by-Slide Breakdown

### Slide 1: Title Slide
**Current:** {Content}
**Problem:** {What's weak}
**Improved:** {New version}
**Tip:** {Design suggestion}

### Slide 2: {Title}
...

## Quick Wins

### Make headlines stronger
Before: "Q4 Results"
After: "Q4: 47% Revenue Growth, Strongest Quarter Yet"

### Add data visualization
Instead of: Table with 20 numbers
Use: Single impactful stat + mini chart

### Reduce text
Before: 5 bullet points
After: 3 bullets max, one main point

### End with action
Before: "Thank you"
After: "Next Steps: 1) Approve by Friday, 2) Kick off Monday"

## Template Improvements

### Problem Slide
Before: List all problems
After: 1 main problem + impact + solution preview

### Solution Slide
Before: Feature list
After: Before/After comparison + customer quote

### Data Slide
Before: Full spreadsheet
After: 1 key insight + supporting numbers

## Commands
| Command | Action |
|---------|--------|
| `improve slides` | Full improvement |
| `slide headline` | Better titles |
| `data viz` | Chart suggestions |
