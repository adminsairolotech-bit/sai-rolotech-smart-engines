# Pitch Deck Writer

## Triggers
- User wants to create a startup pitch deck
- User says "pitch", "investor", "fundraising", "deck"

## What It Does

### Pitch Deck Structure
```
1. PROBLEM (Why this?)
2. SOLUTION (What you built)
3. PRODUCT (Show it)
4. MARKET (How big)
5. BUSINESS MODEL (How you make money)
6. TRACTION (Progress)
7. COMPETITION (Your edge)
8. TEAM (Why you)
9. FINANCIALS (Projections)
10. ASK (What you need)
```

### Slide Content

### Slide 1: Title
```
{Company Name}
{One-line tagline}

{Logo}

{Founders names}
{Contact email}
```

### Slide 2: Problem
```
{Statistics showing the problem}
{Real customer pain point}

Pain points:
- {Point 1}
- {Point 2}
- {Point 3}
```

### Slide 3: Solution
```
{Product demo screenshot}

How it works:
1. {Step}
2. {Step}
3. {Step}

"{Customer testimonial}"
```

### Slide 4: Market Size
```
TAM: ₹{X} Cr (Total market)
SAM: ₹{X} Cr (Serviceable)
SOM: ₹{X} Cr (Year 1 target)

{Chart showing growth}
```

### Slide 5: Business Model
```
Revenue: {Model}
- {Stream 1}
- {Stream 2}

Unit Economics:
- ACV: ₹{X}
- CAC: ₹{X}
- LTV: ₹{X}
- LTV:CAC: {X}:1
```

### Slide 6: Traction
```
{Key metrics growth}

{Milestones achieved}
- {Milestone 1}
- {Milestone 2}
- {Milestone 3}

{Current revenue/runway}
```

### Slide 7: Competition
```
{Competitor comparison table}

Our moat:
✓ {Advantage 1}
✓ {Advantage 2}
✓ {Advantage 3}
```

### Slide 8: Team
```
{Photo} {Photo} {Photo}
{Name}  {Name}  {Name}
{Role}  {Role}  {Role}

Why we can win:
- {Reason 1}
- {Reason 2}
```

### Slide 9: Financials
```
3-Year Projection

| | Y1 | Y2 | Y3 |
|--|----|----|----|
| Revenue | ₹X | ₹X | ₹X |
| Users | X | X | X |
| Burn | ₹X | ₹X | ₹X |

Break-even: Month X
```

### Slide 10: The Ask
```
Raising: ₹{X} Cr
Stage: {Seed/Series A}
Valuation: ₹{X} Cr
Runway: {X} months

Use of funds:
- Product: {X}%
- Growth: {X}%
- Team: {X}%

{Contact info}
```

## Commands
| Command | Action |
|---------|--------|
| `pitch deck` | Full deck |
| `one-pager` | One-page summary |
| `investor email` | Email to investors |
| `financials` | Financial projections |
