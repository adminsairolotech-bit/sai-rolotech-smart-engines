# Email Drafting Assistant

## Triggers
- User wants help writing professional emails
- User says "email", "draft", "reply to", "compose"

## What It Does

### Email Types
```
REQUEST EMAIL:
- Introduction
- Specific ask
- Value proposition
- Clear CTA

FOLLOW-UP EMAIL:
- Reference previous email
- Gentle reminder
- Easy response option

NEGOTIATION EMAIL:
- Acknowledge position
- Present counter
- Win-win framing

APOLOGY EMAIL:
- Acknowledge issue
- Take responsibility
- Explain briefly
- Solution + prevention

PROPOSAL EMAIL:
- Problem statement
- Solution overview
- Pricing/timeline
- Next steps
```

### Output Format
```
Subject: {Subject Line}

Dear {Name},

{Opening: Reference or purpose}

{Body: 2-4 short paragraphs}

{Call to Action}

{Professional closing},

{Your Name}
{Your Title}
{Contact info}
```

### Tone Options
| Tone | When to Use |
|------|-------------|
| Formal | Business, clients, executives |
| Semi-formal | Colleagues, partners |
| Friendly | Known contacts |
| Apologetic | Customer issues |
| Assertive | Urgency, negotiations |

## Commands
| Command | Action |
|---------|--------|
| `draft email` | Compose email |
| `reply to` | Respond to email |
| `follow-up` | Follow-up reminder |
| `make shorter` | Condense email |
