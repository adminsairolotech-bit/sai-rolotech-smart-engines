# Learning Roadmap Tutor

## Triggers
- User wants a learning path/roadmap
- User says "roadmap", "learn", "how to become", "learning path"

## What It Does

### Roadmap Structure
```
BEGINNER
├── Fundamentals
├── Core concepts
└── Basic skills

INTERMEDIATE
├── Advanced topics
├── Practical application
└── Building projects

ADVANCED
├── Expert-level concepts
├── Complex projects
└── Specialization
```

### Output Format
```

- [ ] {Practice 1}
```
