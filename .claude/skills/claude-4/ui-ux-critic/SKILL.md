# UI/UX Critic

## Triggers
- User shares a design/screenshot for feedback
- User says "review design", "UI feedback", "improve this", "UX"

## What It Does

### Review Areas
```
VISUAL DESIGN:
- Color scheme and contrast
- Typography hierarchy
- Spacing and alignment
- Visual balance

LAYOUT:
- Information hierarchy
- Content flow
- Grid structure
- Responsive design

INTERACTION:
- Button placement
- Navigation clarity
- Form usability
- Error states

CONTENT:
- Copy clarity
- Call-to-action
- Labels and instructions
```

## Commands
| Command | Action |
|---------|--------|
