# SOP Writer

## Triggers
- User wants to write standard operating procedures
- User says "SOP", "procedure", "process", "step by step"

## What It Does

### SOP Structure
```
1. PURPOSE
   → Why this SOP exists
   → Who should follow it
   
2. SCOPE
   → Who it applies to
   → When to use it
   
3. DEFINITIONS
   → Key terms explained
   
4. RESPONSIBILITIES
   → Who does what
   
5. PROCEDURE
   → Step-by-step instructions
   → Decision points
   
6. APPENDIX
   → Templates, checklists
```

### Output Format
```
# Standard Operating Procedure: {Title}

## 1. Purpose
**Purpose:** {Why this SOP exists}
**Scope:** {Who it applies to}
**Effective Date:** {Date}
**Review Date:** {Date}
**Version:** {X.Y}

## 2. Definitions
| Term | Definition |
|------|------------|
| {Term} | {Definition} |

## 3. Responsibilities
| Role | Responsibility |
|------|----------------|
| {Role} | {Task} |

## 4. Required Materials
- [ ] {Material 1}
- [ ] {Material 2}
- [ ] {Tool 1}

## 5. Procedure

### Step 1: {Action}
**Action:** {What to do}
**Responsible:** {Who}
**Time:** {How long}

**Sub-steps:**
1.1 {Sub-action}
1.2 {Sub-action}

**Verification:** {How to verify success}

### Step 2: {Action}
...

## 6. Decision Tree
```
{Condition?}
├─ Yes → {Action A}
└─ No → {Action B}
```

## 7. Checkpoints
- [ ] Checkpoint 1
- [ ] Checkpoint 2

## 8. Troubleshooting
| Issue | Solution |
|-------|----------|
| {Issue} | {Solution} |

## 9. Appendix

### Checklist
- [ ] {Check item 1}
- [ ] {Check item 2}

### Template
```
{Template if applicable}
```

## 10. Change Log
| Version | Date | Changes | Author |
|---------|------|---------|--------|
| 1.0 | {Date} | Initial version | {Name} |
```

## Commands
| Command | Action |
|---------|--------|
| `write SOP` | Full SOP |
| `write checklist` | Checklist only |
| `simplify SOP` | Make simpler |
