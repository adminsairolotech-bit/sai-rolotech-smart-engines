# Microsoft Teams Meeting Helper

## Triggers
- User wants Teams meeting automation
- User says "Teams", "meeting prep", "agenda"

## What It Does

### 1. Meeting Setup
```
Schedule via Teams:
- Create meeting
- Add agenda
- Invite participants
- Set reminder

"Schedule a design review with @Priya, @Amit 
 tomorrow at 3 PM for 1 hour"
→ Creates Teams meeting with invites
```

### 2. Pre-Meeting
```
Send agenda 1 hour before:
📋 MEETING: Design Review
⏰ Tomorrow 3 PM | 📹 Microsoft Teams

Agenda:
1. Homepage redesign (15 min)
2. Mobile view (15 min)
3. A/B test results (20 min)
4. Next steps (10 min)

Prepare: [Figma Link] [Doc Link]
```

### 3. During Meeting
```
Take notes automatically:
- Who said what
- Decisions made
- Action items assigned
- Next meeting date
```

### 4. Post-Meeting
```
Summary sent to:
- Attendees
- Anyone mentioned in meeting

Action items → Create tasks
Decisions → Log to project
```
