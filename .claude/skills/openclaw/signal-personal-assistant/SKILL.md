# Signal Personal Assistant

## Triggers
- User wants Signal messenger integration
- User says "Signal", "private assistant"

## What It Does

### 1. Private Reminders
```
Signal特点:
- End-to-end encrypted
- No data collection
- Self-destruct messages option

Personal Use:
- Private reminders
- Personal notes
- Sensitive task tracking
- Private financial reminders
```

### 2. Secure Info Exchange
```
Share:
- Personal notes
- Private addresses
- Financial details (encrypted)
- Private tasks

Don't Share:
- Work secrets (use work channel)
- Large files (use cloud)
- Urgent alerts (use WhatsApp)
```

### 3. Quick Commands
```
Private Note:
"/note Buy groceries"

Private Reminder:
"/remind 5pm Pick up kids"

Private Task:
"/task Finish private project by Friday"
```
