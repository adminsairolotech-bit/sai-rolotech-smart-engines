- **Skills Catalog:** C:\pinokio\api\awesome-openclaw-skills\
- **Local Dev:** http://localhost:3000

## Quick Commands

```bash
# Search skills
clawhub search playwright

# Install skill
clawhub install playwright-testing

# Browse catalog
clawhub explore
```
