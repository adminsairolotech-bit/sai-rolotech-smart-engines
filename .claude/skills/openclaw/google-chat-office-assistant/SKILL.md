# Google Chat Office Assistant

## Triggers
- User wants Google Chat integration
- User says "Google Chat", "Chat bot", "internal chat"

## What It Does

### 1. Common Office Queries
```
Auto-respond to:

LEAVE:
"Who's on leave today?"
→ Show today's approved leaves

HOLIDAYS:
"Next holiday?"
→ Show upcoming holidays

POLICY:
"What are the working hours?"
→ Company policy response

CONTACTS:
"Who's the HR contact?"
→ HR team details

IT:
"How do I reset password?"
→ IT self-service steps
```

### 2. Quick Approvals
```
Leave Request: /approve @manager
Holiday List: /holidays
Team Availability: /who @design
Meeting Rooms: /rooms available 3pm
```

### 3. Status Updates
```
Auto-post to #announcements:
- New employee joining
- Birthday announcements
- Project milestones
- System maintenance
```

### 4. Integration
```
Gmail Calendar → Meeting alerts
Drive → File sharing
Jira/Linear → Project updates
HRMS → Leave management
```
